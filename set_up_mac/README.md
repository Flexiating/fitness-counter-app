# macOS setup

Run `install_python_311.command` before the first launch if Python 3.11 is not
installed.

You can double-click the file in Finder. If macOS blocks it, Control-click the
file and choose **Open**, or run this in Terminal from this folder:

```bash
chmod +x install_python_311.command
./install_python_311.command
```

After the setup finishes, return to the project folder and run `./run_mac.sh`.
